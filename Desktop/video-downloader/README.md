# Video Downloader Pro

A full-stack, production-ready universal video and audio downloader web application constructed with Vanilla Node.js, Express, HTML5, Vanilla ES6 JavaScript,yt-dlp, and FFmpeg.

## System Requirements

- **Node.js**: v18.0.0 or higher
- **FFmpeg**: System-level installation required and added to environment PATH
- **yt-dlp**: System-level installation required and added to environment PATH

### Installation Instructions for System Dependencies
